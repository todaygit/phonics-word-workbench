# 英语学习工作台

左侧分为今日学习、单词背诵、拼写测试、语法测试、设置。所有内容管理位于设置 → 家长控制。

## 内容与记录

- 认词词库与原 v0.8 拼写词库分开。可新建、批量录入、复制 v0.8 章节、编辑、停用和删除；复制后不互相同步修改。
- 认词卡支持中文、音标、拆分、例句出处和配图。图片支持 PNG/JPEG/WebP，最多 1 MB。
- 不认识会保存为重学，再讲解；认出后按阶段安排下一次复习。新词和复习额度按当天纳入的不同词计数，重学不重复计数。待学队列跨日保留。学习日期采用中国时区。
- 默认间隔为 10 分钟、1、2、4、7、15、30 天，每个间隔从最近一次认出时计算，可在学习计划调整。不是对记忆效果的保证。
- 语法题库支持选择题、填空题、多答案和解析。示例题需家长主动加入，标注为自编示例。当前一轮的答案保存，开始新一轮将替换上一轮；不提供历史成绩汇总。
- RAZ 内容尚未导入。设置里的材料位置只是备注，网页不能直接访问电脑文件夹；后续在对话中提供实际材料位置再整理接入。
- 新模块使用 Sites D1（DB）保存记录、R2（MEDIA）保存私有图片，按平台用户标识隔离。使用修订号防止不同页面相互覆盖。更新成功前不会推进卡片，断网或冲突时需重新载入核对。
- 原拼写词库与进度仍使用原有浏览器存储，未迁移或覆盖。完整 JSON 备份包含两部分及图片引用；图片本体保留在相同 Site、相同账户的 R2 中，不是离线图片备份。恢复旧版备份不会清除新模块内容。

## 网上素材与词典录音

认词和拼写共用词典录音控件，按词卡音标匹配，再在相同条件下优先选择来源文件标记为美音的录音。不同词条有不同读音而音标未能匹配时，暂停自动选择，家长可在词条编辑窗口试听后选定。选定的录音随词条备份。拼写答题前不展示录音出处链接或音标，避免透露拼写。

录音通过 Free Dictionary API 发现，保留原始 Commons 录音出处和音频自身许可；不把词典文本许可套用到录音。支持正常/0.75 倍速、重复播放。自动播放可能被浏览器限制，仍需点击“听单词”。没有录音和网络失败有明确提示，设备合成只作为标注清楚的备用选项。并未对完整 v0.8 的每个词人工试听，不能保证所有词都有词典录音。

音频镜像和 Commons 原始录音互为备用；HTTP 错误或超时都会尝试另一来源。浏览器优先播放已发现的 Commons 原音，失败再尝试本站中转与词典镜像；不会静默改成合成声音。5 条已核实的 Commons 文件元数据作为查询故障时的备用，其他词按来源页动态查询。已识别的 “a cat”“to read” 等短语录音排除出单词听写，不混同于独立单词。服务器下载限制为 2 MB，流式检查实际字节数。

认词编辑窗口的“匹配图片和例句”搜索 Commons 与词典例句，结果只在家长候选区显示。采用后才写入词卡；已有 RAZ 例句、配图不会被查询动作覆盖。图片必须来自允许的 Wikimedia 媒体域，保留作者、来源和许可；外链图片可能失效，仍可改用上传。例句带义项、词性和出处，过滤明显不适合儿童的用语仍不能代替语义和适龄审核；没有可用例句时保持空白，不冒充 RAZ。网上来源不保证全天可达或覆盖所有词。

素材接口要求平台登录，源地址由服务器构造或从已校验的词典记录取得，限制重定向目标，拒绝任意音频代理地址。公开词典元数据与具有音频自身开放许可的录音缓存到 R2；网络错误不缓存为“无词条”。`pnpm verify:resources` 验证匹配、同形异读、缺失字段、过滤及来源域名约束。

资料来源：<https://dictionaryapi.dev/>、<https://github.com/meetDeveloper/freeDictionaryAPI>、<https://www.mediawiki.org/wiki/API:Imageinfo>、<https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia>。

## 开发运行

保留 pnpm。`pnpm dev` 启动本地预览；本地平台登录入口为 `/signin-with-chatgpt?return_to=/`。

新数据库结构在 `db/schema.ts`，Drizzle 生成并提交的迁移在 `drizzle/`。生产发布由 Sites 应用迁移。开发时将相同迁移应用到本地数据库 ID `00000000-0000-4000-8000-000000000000`，使用 `.wrangler/state` 作为持久化目录。

验证：`pnpm verify:wordbank`、`pnpm verify:learning`、`pnpm exec tsc --noEmit`、`pnpm build`。`pnpm verify:learning-api` 仅连接 localhost:3000，验证鉴权、保存/读取、冲突和图片接口；结束后恢复测试前的本地学习数据，测试图片留在本地 R2，不涉及生产数据。
