# 英语学习工作台

左侧分为今日学习、单词背诵、拼写测试、语法测试、设置。所有内容管理位于设置 → 家长控制。

## 内容与记录

- 认词词库与原 v0.8 拼写词库分开。可新建、批量录入、复制 v0.8 章节、编辑、停用和删除；复制后不互相同步修改。
- 认词卡支持中文、音标、拆分、例句出处和配图。图片支持 PNG/JPEG/WebP，最多 1 MB。
- 不认识会保存为重学，再讲解；认出后按阶段安排下一次复习。新词和复习额度按当天纳入的不同词计数，重学不重复计数。待学队列跨日保留。学习日期采用中国时区。
- 默认间隔为 10 分钟、1、2、4、7、15、30 天，每个间隔从最近一次认出时计算，可在学习计划调整。不是对记忆效果的保证。
- 语法题库支持选择题、填空题、多答案和解析。示例题需家长主动加入，标注为自编示例。当前一轮的答案保存，开始新一轮将替换上一轮；不提供历史成绩汇总。
- RAZ 内容尚未导入。设置里的材料位置只是备注，网页不能直接访问电脑文件夹；后续在对话中提供实际材料位置再整理接入。
- 新模块使用 Sites D1（DB）保存记录、R2（MEDIA）保存私有图片，按平台用户标识隔离。使用修订号防止不同页面相互覆盖。更新成功前不会推进卡片，断网或冲突时需重新载入核对。
- 原拼写词库与进度仍使用原有浏览器存储，未迁移或覆盖。完整 JSON 备份包含两部分及图片引用；图片本体保留在相同 Site、相同账户的 R2 中，不是离线图片备份。恢复旧版备份不会清除新模块内容。

## 开发与验证

保留 pnpm。`pnpm dev` 启动本地预览；本地平台登录入口为 `/signin-with-chatgpt?return_to=/`。

新数据库结构在 `db/schema.ts`，Drizzle 生成并提交的迁移在 `drizzle/`。生产发布由 Sites 应用迁移。开发时将相同迁移应用到本地数据库 ID `00000000-0000-4000-8000-000000000000`，使用 `.wrangler/state` 作为持久化目录。

验证：`pnpm verify:wordbank`、`pnpm verify:learning`、`pnpm exec tsc --noEmit`、`pnpm build`。`pnpm verify:learning-api` 仅连接 localhost:3000，验证鉴权、保存/读取、冲突和图片接口；结束后恢复测试前的本地学习数据，测试图片留在本地 R2，不涉及生产数据。
